# AI-RECRUITER-PROJECT
1.Title: Extraction task of AI-Recruiter

2.Project overview
The project aims to reduce the time and effort required to manually identify relevant information from resumes

3.Problem statements: Manual extraction of these data might go inefficient due to human errors and be inconsistent. This project automates the work and makes it easier to analyze the resume in a more easier way

4.Installation instruction: Install Python 3.x and MySQL with database creation; Get the clone repository using git i.e(git clone YOUR_GITHUB_REPOSITORY);Install required libraries; Execute DATABASE is done MySQL; Configure database connections and run the code in python

5.Datasets/Database used here are : The collection of skills, technologies and programming languages

6.Methodology: The conversational type of resume is received as input and each word is split and traversed to cross check with technologies, skills and languages fed in the SQL which gives the extracted part of data after verifying.

7.Technologies used: Python, MySQL, SQL, Git, Github

8.Results of the program successfully gave the extracted and needed part from resume. It is accurate enough to solve a lot of testcases.

9.Some of the challenges faced are when there was connection problem in the interface and when it failed to solve a few testcases

10.Future improvements: Candidate recommendation, improved accuracy through advanced NLP and machine learning techniques.
